# WinOptimize-Pro
我做了一個超級輕量的windows 11 系統優化工具 大小僅65kb 可以：
1.一鍵啟用windows
2.關閉windows自動更新
3.關閉windows安全性
4.停用系統還原
5.關閉windows小工具
6.關閉windows搜尋廣告
7.停用自動更新硬體驅動程式
8.停用微軟遙測
9.關閉UAC
10.清理Windows系統保留的存儲空間（刪掉不影響windows執行）
11.關閉休眠
12.在桌面建立edge無痕視窗
13.關閉edge主頁的廣告
14.檔案總管預設打開是「本機」而不是「快速存取」
15.桌面顯示本機 控制台 垃圾桶
16.所有電源設定都變「永不」 電腦永遠不會關機
17.顯示檔案副檔名 並取消選取方塊
18.關閉開始菜單下方的建議
19.關閉檔案總管的建議最近檔案

這個建議在裝完系統就執行能省下不少時間調適系統，也做還原功能不喜歡隨時改回預設！

注意事項：
1.關閉Windows安全性前請先至Windows安全性關閉篡改防護
2.請用管理員身份運行
3.初次打開U A C會提示位置的開發者請暗「是」
